SOMNA

眠ることを頑張らず、心を別の場所へ向ける就寝前の体験。

Summary

眠ろうと意識するほど、かえって眠れなくなってしまうことがある。
Somnaは、そんな就寝前の時間に着目したアプリである。眠るための努力を促すのではなく、気持ちに寄り添った小さな体験を通じて、自然と意識を別の方向へ向けられることを目指した。

瞑想や睡眠記録、習慣化のためのリマインダーといった機能を充実させるのではなく、まずは「今、どんな気持ちで眠れずにいるのか」を尋ねる。回答に応じて、流れ星を捕まえたり、窓の向こうの風景を眺めたりといった、静かなアクティビティへと案内する。

ユーザーがあれこれ考えたり、選択に迷ったりすることなく、気の向くままに過ごせる体験を目指した。

The Problem

眠ろうとすることが、かえって眠りを妨げてしまう。

「早く眠らなきゃ」「明日は朝早いのに」「どうして眠れないんだろう」

ベッドに入っても、そんな考えが頭から離れず、余計に目が冴えてしまうことがある。疲れているのに眠れない焦りが、さらなるストレスにつながるためだ。

睡眠やウェルネスを支援する既存のアプリには、瞑想や睡眠音の選択、呼吸法、睡眠記録など、さまざまな機能が用意されている。一方で、それらを利用するには、何をするかを選び、実際に取り組む必要がある。日中であれば便利なこうした機能も、心身ともに疲れている就寝前には、負担に感じられるかもしれない。眠るために何かをしなければならない。そのプレッシャー自体を、少しでも減らせないだろうか。

The opportunity

眠るために頑張るのではなく、自然と気持ちを切り替えられる体験へ。

もし、アプリが眠るための努力を求めず、ただ気持ちを別の方向へ向けるきっかけをつくれたら。

今の気分に合った小さな体験に身を任せることで、眠れないことへの焦りから少し離れられるのではないか。
この考えをもとに、Somnaのコンセプトを構想した。

Design Hypothesis

設計にあたって考えたこと

Somnaの体験を設計するにあたり、次の問いを出発点とした。

  • 疲れているのに眠れないとき、頭の中では何が起きているのか。
  • 眠れないときに、ユーザーはどのような過ごし方を求めているのか。
  • 就寝前のアプリにとって、機能や選択肢の多さは本当に必要なのか。
  • 頭の中で考えが巡っているとき、穏やかなアクティビティが気持ちを切り替えるきっかけになり得るか。
  • そのときの気分に合わせて体験を変えることで、より無理なく利用できるのではないか。

これらを設計上の仮説として整理し、既存サービスの特徴やコンセプトとの違いを踏まえながら、Somnaの体験を具体化した。

Competitors

Calm

ストーリーやサウンドスケープなど、リラックスするためのコンテンツが充実している。一方、コンテンツが豊富な分、何を利用するかをユーザー自身が選ぶ必要がある。

Headspace

ガイド付き瞑想やマインドフルネスのプログラムを通じて、心を整える習慣を支援する。目的を持って取り組む体験に強みがある一方、何も考えずに過ごしたいときには、少し能動的な体験ともいえる。

BetterSleep

睡眠音やリラクゼーションに関する幅広いコンテンツを提供している。さまざまな好みに対応できる反面、選択肢の多さが、就寝前のユーザーにとって負担になる可能性もある。

Target Users

Somnaが想定するのは、疲れているにもかかわらず、さまざまな理由で寝つけずにいる人である。 例えば、日中の出来事を思い返してしまう人、明日の予定や仕事が気になる人、落ち着かない気持ちが続いている人など。 同じ「眠れない」という状態でも、その背景にある気持ちは人によって異なる。そこで、ユーザーの気分に応じて体験を変えられる設計を考えた。

マヤ（29歳）— 夜になると考え込んでしまう人

日中は仕事に集中しているものの、就寝時間になると、さまざまな考えが頭に浮かんでしまう。 ベッドに入ると、日中の会話を思い返したり、翌日の予定を心配したりする。すぐに答えが出ないことまで考え続けてしまい、疲れているのになかなか気持ちを切り替えられない。 そんなときに必要なのは、さらに何かを頑張ることではなく、考え続ける状態から少し離れるためのきっかけかもしれない。

Design Insights

#1

「眠れない」背景にある気持ちに目を向ける

眠れない理由は、単に眠気が足りないからとは限らない。明日のことが心配だったり、頭の中で考えが巡っていたり、気持ちが落ち着かなかったりすることもある。
一律に同じコンテンツを提供するのではなく、今の気分に合った体験へ導くことを設計の軸とした。

#2

選択肢を増やすより、迷わず始められることを優先する

コンテンツが豊富であることは、普段使いでは便利な一方、疲れているときには選ぶこと自体が負担になり得る。
そこでSomnaでは、アクティビティを一覧から選ぶのではなく、最初に気分を選ぶだけで次の体験へ進める構成とした。

#3

ただリラックスを促すのではなく、自然と意識を向けられるものを用意する

「リラックスしよう」と意識することさえ難しいときもある。
そこで、流れ星を捕まえる、砂に線を描く、窓の向こうを眺めるといった、小さなアクティビティを用意した。無理に何かを達成するのではなく、ほどよく意識を向けられる対象をつくることを意図している。

#4

そのときの気分に合わせて、過ごし方を変えられるようにする

頭の中で考えが巡っているときと、落ち着かない気持ちが続いているときでは、心地よく感じる過ごし方も異なる可能性がある。
Somnaでは、気分に応じて異なるアクティビティへ案内することで、一人ひとりの状態に寄り添う体験を目指した。

Project goals

「眠らなければ」というプレッシャーを減らす。Somnaのコンセプトを具体的な体験に落とし込むにあたり、次の5つを設計の指針とした。

  1. 選ぶ手間を減らす
    最初に今の気分を選ぶだけで、アクティビティを始められるようにする。
  2. 意識を別の方向へ向ける
    眠ること自体を意識させるのではなく、穏やかに集中できる対象を用意する。
  3. 気分に合わせた体験を提供する
    一律のコンテンツを提示するのではなく、そのときの気持ちに応じて異なるアクティビティへ導く。
  4. 評価や達成を求めない
    スコアや連続利用の記録、目標設定などは設けず、できた・できなかったを意識させない。
  5. 心地よく過ごせる空間をつくる
    色彩や動き、インタラクションを通じて、日中の作業画面とは異なる、静かで落ち着いた雰囲気を演出する。

User Flow

ユーザーが行うのは、今の気分を選ぶことだけ。その後のアクティビティは、選んだ気分に応じて案内される。
何をするかを一つひとつ選ぶ必要がないため、迷わず体験を始められる構成とした。

Branding

日常から少し離れ、静かな空間に身を置くような体験へ。Somnaでは、情報を効率よく確認したり、目標の達成を促したりする一般的なアプリとは異なる雰囲気を目指した。イメージしたのは、夜、静かな部屋に入っていくような感覚である。落ち着いた色彩や柔らかな光、控えめなアニメーションを組み合わせ、操作を急かすことなく、自然とその場にとどまりたくなるようなビジュアルを設計した。

Hi-Fi Screens

Landing screen

アプリを開いた瞬間から、日中とは異なる静かな時間へ切り替えられるように設計した。ロゴには穏やかな明滅の動きを加え、過度に注意を引くことなく、ゆっくりと体験に入っていけるようにした。

Select the feeling

ユーザーが今の気分を選ぶ画面。 アクティビティそのものを選ばせるのではなく、まず自分の状態に目を向けてもらう。その選択を起点に、次の体験へ自然につながる構成とした。

Activity #1: Catching falling stars

画面に流れてくる星をタップして捕まえるアクティビティ。目の前の小さな動きに意識を向けることで、頭の中で巡る考えから少し離れるきっかけをつくる。難しい操作や達成目標は設けず、気軽に触れられる体験とした。

Activity #2: Sand Garden

指先を動かし、砂の上に自由に線を描くアクティビティ。決まった手順や正解を設けず、自分のペースで画面に触れられるようにした。指先の動きと画面上の変化を楽しみながら、気持ちを落ち着けられる体験を目指した。

Activity #3: Window Into Somewhere

窓の向こうに広がる、どこか遠くの風景を眺めるアクティビティ。操作をほとんど必要とせず、ただ景色を眺めて過ごせる。何かに取り組む気力がないときにも利用できる、受動的な体験として設計した。

Activity #4: Gentle Reflection

穏やかな言葉に触れ、自分の気持ちを少しずつ緩めていくアクティビティ。何かを考えたり、答えを出したりすることを求めず、言葉をそのまま受け取れるようにした。

Somnaのコンセプトと、4つのアクティビティを紹介するプロモーションビデオ。

Results

コンセプトを実際に触れて確かめられるプロトタイプへ。 Figma Makeを活用し、気分の選択から各アクティビティの体験まで、一連の流れを操作できるインタラクティブなプロトタイプを制作した。
Somnaプロトタイプ

主な実装内容は以下のとおりである。

  • 気分を選択して体験を始めるオンボーディング
  • 流れ星をタップして捕まえるインタラクション
  • 景色を眺められる「Window Into Somewhere」のアニメーション
  • 指先で砂に線を描くインタラクション
  • 穏やかな言葉に触れる「Gentle Reflection」
  • 静かな世界観を表現するビジュアルとアニメーション
  • モバイルを中心としたレスポンシブデザイン

アイデアを画面のデザインにとどめず、実際の操作を通じて体験できる形にすることで、Somnaが目指す利用の流れを具体化した。Somnaで大切にしたのは、ユーザーに眠るための努力を求めないことである。何かを達成したり、正しい方法を実践したりするのではなく、ただ気持ちを別の方向へ向けられる時間をつくる。

選択肢を増やすことが、
必ずしも使いやすさにつながるとは限らない。

Somnaの設計では、機能を充実させることよりも、ユーザーが迷わず体験を始められることを重視した。 睡眠に関するコンテンツを幅広く集めるのではなく、気分に応じた少数のアクティビティへ導く。選択の負担を減らし、必要以上に何かを意識させない。
