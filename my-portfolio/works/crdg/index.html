デジタルエンターテインメント企業のコーポレートサイトリデザイン

Summary

ゲームやクリエイティブコンテンツを手がけるデジタルエンターテインメント企業のコーポレートサイトをリデザインした。

事業の拡大に伴い、採用情報が各部署に分散し、既存サイトでは企業の規模やクリエイティブな活気を十分に伝えられていなかった。企業文化や実績を一元的に発信し、採用と営業の両面を支えるプラットフォームとして再構築することを目指した。

プロジェクトは3つのフェーズで進行した

  1. 採用ページのリデザイン — 企業のリアルな魅力と熱量を伝える
  2. トップページのリニューアル — ブランドアイデンティティを伝える
  3. Work Archiveの構築 — クリエイティブ実績を魅力的に紹介する

また、Webサイトと営業戦略・社外向けコミュニケーションの方向性を揃えるため、プレゼンテーション資料のデザインも担当した。

My Contributions

Lead Web Designer & UX Plannerとして、以下を担当した。

  • サイト全体の構成とページ階層の設計
  • 競合・ユーザーリサーチ
  • レイアウト、ビジュアル、レスポンシブコンポーネントの設計
  • 社員インタビューの撮影ディレクションとコンテンツ制作
  • マーケティング・人事チームとの連携によるサイト目的の整理

Outcome

リニューアル後、問い合わせ数は200%増加し、社内からも部署間のコミュニケーションや採用判断がスムーズになったという評価を得た。数値以上に大きな成果は、Webサイトが初めて企業のアイデンティティを明確に表現できるようになったことだった。個性、コラボレーション、成長を大切にするクリエイティブ企業としての姿を、サイト全体で表現した。

Recruitment Page

採用ページでは、企業をより身近に感じてもらい、応募者と実際に働く社員との心理的な距離を縮めることを目指した。単なる「求人情報」のページではなく、社員のストーリーやビジュアルを通して企業文化を知れる体験として設計した。

ビジュアルの階層とストーリーテリングを重視し、社員のポートレートにガラスの質感やパステルカラーのグラデーションを重ねた印象的なヒーローセクションから始まる構成とした。AppleのmacOSのデザイン言語から着想を得たGlassmorphismを採用し、クリエイティブ性とトレンド感を表現した。

パステルカラーは全体の調和を保ちながら、多様性のある企業文化を象徴する要素として使用した。各セクションで異なるレイアウトのリズムを作り、スクロール中も興味を維持できる構成とした。

Content Structure & Features

  • Hero Visual

    実際の社員を起用したビジュアルと、企業文化やミッションを表現するリアルなタグラインを組み合わせた。透明感のあるレイヤーと柔らかなカラーによって、開放的で温かみのある企業文化を表現した。

  • About the Company

    企業の理念、コアバリュー、クリエイティブな環境を簡潔に紹介。堅い企業用語を避け、親しみやすい言葉とトーンで企業の魅力を伝えた。

  • Pick-Up Positions

    現在需要の高い職種をカルーセルやカード形式で紹介。各カードから詳細な求人情報へ直接アクセスできる構成とし、企業についてまだ詳しく知らないユーザーにとっても、興味を持つきっかけとなるセクションとして設計した。

  • Interview Integration

    部署責任者やメンバーが実際の仕事について語る、ストーリーテリングの中心となるコンテンツ。
    各インタビューでは以下を紹介した。
    チーム概要と仕事内容
    仕事へのモチベーションや課題
    未来の応募者へのアドバイスやメッセージ
    画像の配置を左右交互にすることで、スクロール時の視覚的なリズムを作った。

  • Application Flow

    明確なCTAと応募状況を示すインジケーターを配置し、求人情報の閲覧から応募完了までのステップを理解しやすくした。

    また、メンター制度やスキルアップの機会、若手クリエイターの育成方針を紹介するセクションを設け、入社後の成長もイメージできる構成とした。

Top Page

トップページは企業のデジタル上の「入口」として設計した。目的は、一般ユーザーに企業のクリエイティブなアイデンティティを伝えることと、採用・営業の両方につながる戦略的な接点をつくることだった。

以前のトップページは構成やコンテンツの深さに課題があったため、マーケティングチームと協働し、拡大するスタジオと事業領域を軸にコンテンツを再構成した。

エンターテインメント企業らしい躍動感と、企業サイトとしての明快さを両立するビジュアルトーンを設計。 社内クリエイターによる作品をスライド表示するキービジュアルを採用し、クリエイティブ企業としての実績と、ビジネスパートナーとしての信頼感を同時に表現した。

Content Structure & Features

  • Hero Visual Slider

    社内スタジオが制作した代表的なプロジェクトをダイナミックなカルーセルで紹介。スムーズなトランジションとコンテキストに合わせたキャプションによって、クリエイティブの品質と実績を最初の画面から伝えた。

  • Corporate Message

    企業のビジョンや理念を紹介する、簡潔で印象的なタグラインを配置。ヒーロー直下に置くことで、企業の考え方を早い段階で伝え、ユーザーとの感情的な接点をつくった。

  • Service & Studio Overview

    ゲーム制作からデジタルコンテンツ制作まで、各スタジオの専門領域をモジュール型のグリッドで紹介。各ブロックから詳細ページへ移動でき、事業内容をスムーズに探索できる構成とした。

  • Related Services, Blog & News Section

    イベント制作、教育プログラム、パートナーシップなどの関連事業を紹介。カラフルなアイコンとカードを用いて、企業が持つ多様な事業領域を表現した。また、最新の活動やインタビュー、ニュースを表示するフィードを設け、サイトの鮮度を保ちながら継続的な訪問を促した。

Work Archive

スタジオの実績を見やすく、一元的に管理する

リニューアル前は9つのスタジオがそれぞれ独自の「Works」セクションを管理しており、表示方法が統一されていなかった。 そこで、すべてのプロジェクトを一元的に紹介しながら、ユーザーが直感的に作品を探索できるアーカイブを構築した。

デザインの核としたのはシンプルさ。デジタルギャラリーのように、画像を主役としたクリーンで柔軟なインターフェースとした。

大きなビジュアル、明確な情報階層、ミニマルなフレームによって、トップページとトーンを揃えながら、各プロジェクトそのものに視線が向かう設計とした。

Features

  • Unified Project Grid

    すべてのプロジェクトを一覧できる、メイソンリー形式のグリッドを採用。画像を主役とし、タイトルはホバー時に表示することで、ミニマルな印象を保った。

    Filtering System

    カテゴリーによる絞り込み機能を実装。ページ遷移を必要とせず、動的に結果を更新することで、探索の流れを妨げない設計とした。

    Project Detail Pages

    各プロジェクトの詳細ページには、大きなヒーロー画像または動画、プロジェクト概要、関連するスタジオ情報を掲載。

    Studio Integration

    各プロジェクトから関連するスタジオページへ直接移動できる導線を設けた。サイト全体のブランド統一を強化し、コンテンツ間の回遊性を高めた。

    CMS Management (WordPress Integration)

    レイアウトの品質を保ちながら、担当者が直感的かつスピーディーに作品を追加できるCMS設計とした。

Result

リニューアル後、以下の成果につながった。

  • 問い合わせ数が200%増加
  • 採用情報の一元化による応募体験の改善
  • 部署間の連携強化
  • 企業の成長に合わせて拡張できる柔軟なWeb構造を構築

Reflection

本プロジェクトを通して、コーポレートサイトは単なる情報設計の場ではなく、企業が何者であり、なぜ人がそこで働き、なぜ企業と協働したいと思うのかを伝える場でもあると学んだ。クリエイティブ性と構造のバランスを取ることで、動的なビジュアル表現だけでなく、ビジネス上の成果にもつながるWebサイトを設計できた。
