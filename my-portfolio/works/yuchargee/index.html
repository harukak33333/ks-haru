ゆうちゃみさんの充電体験を楽しくする

Summary

ゆーちゃーじぃは、明るくポジティブなモデル・タレントのゆうちゃみさんが抱える数少ない日常の悩み、「スマートフォンの充電」を楽しく習慣化するためのアプリ。
ユーザーリサーチや課題定義、コンセプト立案、デザイン、実装までを6週間で行った。
GIFTech 2024 Springでプロジェクトを発表し、強いオーナーシップと革新的なデザインが評価され、チームで1位を獲得した。

Links

  • GIFTech 2024 Spring

My Contributions

UI/UX Designerとして、リサーチの整理、コンセプト設計、ビジュアルデザインをリードした。エンジニアやプロジェクトマネージャーと密に連携し、ゆうちゃみさんの明るい性格やライフスタイルを反映したアプリ体験を設計した。

Outcome

ゆーちゃーじぃは、何気ない充電という行為を、楽しさと自発性を生み出す体験へと変えた。 行動心理学、遊び心のあるUI、ユーザーへの深い理解を組み合わせることで、ゆうちゃみさんの生活や個性に自然に馴染むプロダクトを実現した。

Process

  • ゆうちゃみさん本人とマネージャーへのユーザーインタビュー
  • 行動パターンとモチベーションの要因を特定
  • エンパシーマップと課題のリフレーミングによるコンセプト設計
  • インタラクションフローとゲーミフィケーションによるフィードバック設計
  • デモ発表に向けたビジュアルデザインとプロトタイプ制作

Understanding the Challenge

最初の、そして最大の課題はインタビューだった。ゆうちゃみさんは自信を持って「悩みは何もない」と話した。常にポジティブな姿勢で、何事も前向きに捉える人物として知られている。

しかし、会話を深める中で、ひとつのチャーミングな事実が見えてきた。ゆうちゃみさん自身が「面倒くさがり」と表現するほど、スマートフォンの充電をマネージャーや母親に頼むことが多かった。これが今回のインサイトとなった。

「生活を楽にする」のではなく、小さな行動を自分自身で起こせるようにしながら、それ自体を楽しい体験にできないか？

そこから生まれたのが、「人を助けることは、自分自身を助けることから始まる」というコアコンセプトだった。

Design Question

方向性が決まった後、次の問いに向き合った。
どうすればゆうちゃみさんが自発的にスマートフォンを充電するようになるか？

充電を避ける主な理由はシンプルだった。「立ち上がって充電器まで歩くのが面倒。」そこで、充電を避けるものではなく、楽しみにできる遊び心のある体験へ変える方法を探った。

Key Features

  • 1. Smart Charging Reminder

    アプリはゆうちゃみさんが自宅に近づくと、充電の時間を知らせる通知を送る。充電器を接続すると、占いやおみくじが好きな彼女に合わせ、デジタルおみくじを引ける仕組みとした。

  • 2. Interactive Charging Widget

    スマートフォンのバッテリー残量を視覚的に表現する、アニメーション付きのキャラクターウィジェットを設計した。キャラクターは「サイバー空間」に暮らし、充電中はかわいく生き生きと動く。一方、バッテリー残量が減るにつれて徐々に元気を失っていく。

  • 3. Manager Connection via LINE

    LINEと連携し、バッテリー残量をマネージャーのアカウントと共有できる仕組みを実装した。スマートフォンの電源が切れる前に、マネージャーからも充電を促せるようにした。

  • 4. Character Collection Screen

    生成されたキャラクターを一覧で確認・収集できるコレクション機能を設計した。充電そのものを、ゲームのように楽しめる体験へ変えることを狙った。

Logo Design

アプリのデザインが完成した後、さらに魅力を高めるため、アイコニックなロゴを制作した。

Key Features

  • ゆうちゃみさんの印象に残るデザインを意識
  • ゆうちゃみさん世代に馴染みのあるハッシュタグをデザインに取り入れた
  • インタビューやゆうちゃみさんのSNSから、ピンクとイエローをキーカラーとして選定
  • 電流の波形、稲妻、電源プラグを想起させるモチーフでアプリの機能を表現

Reflection

このプロジェクトを通して、特に「問題」と呼べるほどではない日常の行動に対しても、感情に訴えるデザインが大きな力を持つことを学んだ。ゆーちゃーじぃの設計を通して、UXは単にペインポイントを解決するだけではなく、ユーザーが思わず笑顔になるようなポジティブな感情を生み出すこともできると実感した。
