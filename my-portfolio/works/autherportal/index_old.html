著者専用ポータルサイト

著者のための契約書、支払明細書等の書類管理用ポータルサイト

Summary

This project involved designing a portal site for authors contributing to a major publishing company, aimed at centralising administrative documents that were previously handled mostly on paper.

The portal allows authors to manage invoices, contracts, and payment statements in one place, improving efficiency and transparency for both the authors and the publisher. The site was built using Salesforce Experience Cloud, and I was responsible for the UI design and front-end implementation.

While the required screens and content elements were predefined by the client, the project focused on optimising layout, usability, and visual design to create a clear, accessible, and branded user experience.

My Contributions

As the UI Designer on this project, I worked closely with both the client and Salesforce engineers to ensure a smooth implementation.

  • Conducted visual research on comparable portal and SaaS services
  • Proposed screen layouts and UI structures based on predefined content requirements
  • Designed the full UI after layout approval
  • Implemented front-end code using HTML, CSS, and JavaScript
  • Collaborated with Salesforce engineers to ensure the UI was easy to integrate with backend logic and data structures

Outcome

The resulting portal successfully transitioned document management from paper-based workflows to a digital experience that is both accessible and brand-aligned. By combining familiar Salesforce UI patterns with thoughtful customization, the site supports users of varying digital literacy levels while reinforcing the publisher’s identity. The project demonstrates a practical balance between usability, technical constraints, and visual differentiation within an enterprise platform.

Understanding the Challenge

The project presented two key challenges:

  • Accessibility for a wide age range: Many users were senior authors, making clarity and ease of use critical. Interfaces needed to be immediately understandable, with minimal cognitive load.
  • Balancing usability and brand identity: While Salesforce-based portals often follow standardized UI patterns, the client required a design that felt original and aligned with their corporate identity.

The challenge was to maintain familiarity and usability while introducing a distinct visual character.

User Flow Overview

The flow was designed to minimize navigation depth and ensure senior users can always return to the dashboard with a single action. List–detail patterns were kept consistent across documents to reduce cognitive load.

Solution & Key Design Decisions

To address these challenges, the following design strategies were applied:

  • 1. Familiar yet customized UI elements

    UI patterns were based on existing Salesforce design conventions to reduce learning cost, while originality was added through the use of the company’s symbol mark as a background motif and the application of secondary corporate colors throughout the interface.

  • 2. Clear information hierarchy

    Layouts were designed to prioritize readability, with carefully structured spacing, typography, and component grouping to support users who may be less comfortable with digital tools.

  • 3. Mobile navigation optimization

    For mobile views, the main navigation combined icons and text labels. Scroll-based behavior was introduced to preserve screen space without sacrificing discoverability or usability
