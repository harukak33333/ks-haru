Family Tree Bottle

離れて暮らす大切な人と繋がりを感じるためのアプリ

Summary

離れて暮らす大切な人は、今日どんな一日を過ごしたのだろう。
「Family Tree Bottle」は、そんなふとした思いに寄り添い、離れて暮らす家族や恋人が、日々の気持ちを通してゆるやかにつながるためのWebアプリである。
ユーザーは、その日の気持ちに合った色を選び、共有のボトルに投稿する。長いメッセージを書いたり、相手の返信を待ったりする必要はない。言葉にするほどではない気持ちも、色として共有することで、お互いの存在を身近に感じられる体験を目指した。
Google UX Design Certificateの学習プロジェクトとして企画・デザインを行い、Claude Codeを活用したバイブコーディングにも取り組んだ。UIデザインにとどまらず、インタラクションの設計から動作するプロトタイプの実装まで、一貫して制作した。

The Problem

離れて暮らす家族と、無理なくつながり続けるには？

留学や就職、転勤などをきっかけに、家族や親しい人と離れて暮らすことがある。
新しい環境での生活は、仕事や学業、日々の家事などで忙しく、目の前のことをこなすだけでも精一杯になりがちだ。そんな日々の中で、ふと家族のことが気になったり、自分の不安を誰かと共有したくなったりすることがある。
一方で、相手にも生活があることを考えると、頻繁に連絡するのをためらってしまう。特に伝えたいことがなければ、メッセージを送るきっかけも生まれにくい。
連絡を取ればつながりを感じられる。それでも、連絡すること自体が負担になれば、習慣として続けるのは難しい。

そこで、次の問いを設定した。
親しい人と離れて暮らしていても、連絡の負担を感じることなく、日々のつながりを実感できる体験をつくれないだろうか。

The opportunity

「連絡を取る」ことと、「つながりを感じる」ことを切り離して考える。
既存のコミュニケーションサービスでは、メッセージや写真を送る、通話をするといった、何らかの情報を相手に伝える行動が中心となる。
しかし、日々のつながりを感じるために、必ずしも毎回会話をする必要はないのではないだろうか。
例えば、「今日は少し疲れた」「なんとなく気分がいい」といった小さな感情を、言葉にせず共有できたら。
相手の反応を求めることなく、お互いの存在や日々の様子を感じられるかもしれない。
そこで、コミュニケーションの負担を減らしながら、つながりを実感できる仕組みに着目した。

Project goals

  1. 離れていても、つながりを感じられる
    毎日の気持ちを共有することで、相手の存在を身近に感じられる体験を目指す。会話や返信がなくても、お互いを気にかけていることが自然に伝わる仕組みを考える。
  2. 忙しい日々の中でも、無理なく続けられる
    投稿に必要な操作や心理的な負担を最小限に抑える。同時に、日々の投稿が少しずつ積み重なること自体に意味を持たせ、自然と使い続けたくなる仕組みをつくる。

Competitors

既存のコミュニケーションサービスを比較し、それぞれの特徴と利用時に生じ得る負担を整理した。

これらのサービスは、それぞれ異なる形で人とのつながりを支えている。一方、日常的なつながりを感じるための手段としては、相手に何かを伝えたり、時間を合わせたりする必要がある。
Family Tree Bottleでは、既存のサービスを置き換えるのではなく、会話やメッセージを必要としない、新しい接点をつくることに可能性を見出した。

InstagramなどのSNS

日常の写真や出来事を投稿し、相手の近況を知ることができる。リアクションを通じて気軽に交流できる一方、投稿内容を考えたり、不特定多数からの反応を意識したりする場面もある。

LINEなどのメッセージアプリ

時間や場所を問わず、テキストや写真でコミュニケーションを取れる。自分のタイミングで返信できる一方、送る内容を考えたり、返信をしたりすることが負担になる場合もある。

FaceTimeなどの通話アプリ

声や表情を通じて相手の様子を知ることができ、距離を感じにくい。一方で、お互いの都合を合わせる必要があり、時差や生活リズムが異なる場合には利用のハードルが上がる。

Target Users

2つのユーザーペルソナを設定した。
2人に共通しているのは、相手を大切に思っていても、日々の連絡を継続することは簡単ではないという点だ。

そこで、コミュニケーションの頻度を増やすのではなく、つながりを感じるために必要な行動そのものを小さくすることを設計の出発点とした。

ユキ｜24歳

オーストラリアでワーキングホリデー中 東京出身。新しい環境での生活を楽しみながら、語学学校とアルバイトで忙しい日々を送っている。家族とは仲が良いものの、日々の出来事を逐一報告する習慣はなく、気づけば数週間連絡していないこともある。

  • 家族が元気に過ごしていることを、もっと身近に感じたい
  • 忙しい日でも、気軽に家族との接点を持ちたい
  • 連絡できていないことへの罪悪感を減らしたい

タイキ｜31歳

インドに駐在中 福岡出身。建築関連のプロジェクトに携わり、海外で生活している。妻は神奈川で暮らしており、離れていてもお互いのことを気にかけている。慣れない環境で食生活が変わり、体重が減っていることを妻から心配されている。

  • 自分の生活や気持ちを、無理なく相手に伝えたい
  • 相手に余計な心配をかけずに、日々の様子を共有したい
  • お互いの忙しさを気にせず、つながりを感じたい

Key Insights

これらの仮説をもとに、サービスの方向性を検討した。

ユーザーリサーチによって検証された結果ではなく、課題設定や競合分析を通じて整理した設計上の仮説である。

#1

相手からの反応が、つながりの実感につながるのではないか

SNSでは、相手が投稿を閲覧したりリアクションを返したりすることで、自分の発信が届いたと感じられる。必ずしも会話が生まれなくても、相手が自分の存在に気づいてくれたとわかることには意味があると考えた。
Design Implication： 投稿者に負担をかけずに、相手が投稿を受け取ったことや、関心を寄せていることが伝わる仕組みを検討する。」

#2

つながりを感じるための行動は、手軽である必要がある

離れて暮らす人同士は、それぞれ異なる生活リズムの中で仕事や学業、家事などをこなしている。つながりを保つために時間や労力が必要になると、忙しい日には後回しになりがちだ。
Design Implication： 短時間で完了し、特別な準備を必要としない投稿体験を設計する。

#3

相手を思っていても、連絡のきっかけがない

日常の中で相手を気にかけていても、わざわざメッセージを送るほどの出来事がなければ、連絡を取らないまま時間が過ぎてしまうことがある。
Design Implication： 伝えるべき話題がなくても成立する、気持ちを選ぶだけのコミュニケーションをつくる。

#4

日々の小さな変化に気づける余地がある

離れて暮らしていると、相手の体調や気分の変化をすぐに知ることが難しい場合がある。後になって初めて、相手がつらい時期を過ごしていたと知ることもある。
Design Implication： 日々の気持ちを蓄積し、いつもと違う様子を振り返るきっかけをつくる。ただし、色だけで相手の健康状態を判断するのではなく、あくまで相手を気にかけるきっかけとして位置づける。

Concept

気持ちをひとつ、ボトルに入れる。家族みんなで、ひとつの木を育てる。

Family Tree Bottleでは、その日の気持ちを色に置き換え、共有のボトルに入れるというシステムを採用した。
ユーザーは、気持ちに合う色を選んで投稿する。必要であれば短いメモを添えることもできるが、何も書かずに投稿することもできる。
それぞれの投稿はボトルの中に蓄積され、投稿が増えるにつれて、ボトルの中の木が少しずつ成長していく。自分ひとりではなく、家族みんなの気持ちによって木が育っていくことが、日々の参加を促す小さな動機になることを狙った。
大切なのは、毎日必ず投稿することではない。投稿しない日があっても負担や罪悪感を感じず、気が向いたときに立ち寄れる場所であることを目指した。

User Flow

ユーザーが迷わず気持ちを投稿できるよう、体験をシンプルな流れに整理した。

Emotion & Color System

Gloria Willcoxの感情色相環を参考に、Positive / Negativeの縦軸とCalm / Energeticの横軸からなる独自の感情モデルを設計した。4象限をそれぞれ2つに分け、計8種類の感情を定義。初期状態には、ニュートラルな感情として「Ordinary」を設定した。

Hi-Fi UIでは、各感情に割り当てた色を、Family Treeの養分となる水滴をイメージしたバブルに適用。濡れたような質感を加えることで、日々の感情がボトルに蓄積され、木の成長につながるというコンセプトを視覚的に表現した。

Hi-Fi Screens

最終的なUIでは、ボトルや木を中心としたビジュアルを通じて、家族の気持ちが少しずつ積み重なっていく世界観を表現した。
画面ごとの役割を明確にしながら、操作に迷わないシンプルさと、触れてみたくなる柔らかなビジュアルの両立を目指している。

Bottle — 共有の場所

アプリの中心となる画面。ボトルの中に蓄積された気持ちと木の様子を通じて、家族の共有スペースであることを視覚的に伝える。

Choose Feeling — 気持ちを選ぶ

文章を考えることなく、色を選ぶだけで今の気持ちを表現できる画面。直感的に操作できることを重視した。

Add a Note — 言葉を添える

伝えたいことがある場合だけ、短いメモを追加できる。入力を必須にしないことで、投稿のハードルを下げる。

Collect Feeling — 気持ちを届ける

選んだ気持ちをボトルに加える体験。操作の結果が視覚的にわかることで、自分の投稿が共有スペースに反映されたことを実感できる設計を目指した。

Archive — 気持ちを振り返る

過去の投稿を一覧で確認できる画面。日々の気持ちの積み重ねを振り返り、相手や自分の様子を知るきっかけをつくる。

Implementation

デザインを、操作できるプロトタイプへ。

UIデザインに加え、Claude Codeを活用したバイブコーディングを通じて、Webプロトタイプの実装にも取り組んだ。
デザインを静的な画面として完成させるだけでなく、ユーザーがどのように操作し、その結果がどのように画面へ反映されるのかを具体化することを目指した。
実装を通じて、画面間の遷移やインタラクションを実際に動かしながら確認できる形にした。これにより、デザイン上のアイデアを操作可能な体験として表現するところまで取り組んだ。

Results

今回の制作では、課題設定からコンセプト設計、UIデザイン、プロトタイプ実装までを一貫して行った。
特に、日々の気持ちを色で共有するというアイデアを、ボトルと木のメタファー、投稿フロー、具体的なUIへと落とし込み、操作可能なWebプロトタイプとして形にした点が成果である。
また、Claude Codeを活用することで、デザインと実装を行き来しながら、アイデアを具体的なユーザー体験へと発展させるプロセスに取り組んだ。

つながりを生む体験は、機能の多さよりも、
使うときの心理的な負担によって左右される。

Family Tree Bottleでは、相手にメッセージを送ることではなく、気持ちを色で共有することを体験の中心に据えた。
何かを伝えなければならないというプレッシャーを減らすことで、コミュニケーションの新しい形を提案できたと考えている。
一方で、気持ちを色で表現するだけで本当に相手の様子を理解できるのか、
投稿への反応がなくてもつながりを感じられるのか、といった点は今後検証すべき課題である。
今後は、実際のユーザーにプロトタイプを試してもらい、投稿のしやすさや共有体験の受け止め方を確認したい。
また、家族間での共有方法や、気持ちの変化を振り返る体験についても検討し、日々の生活に自然に溶け込むサービスへと発展させていきたい。
