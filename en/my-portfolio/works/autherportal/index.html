#UI/UX Design #Web app

Salesforce Author Management Portal

A Salesforce Experience Cloud portal to digitize document management for publishing authors

Summary

A digital portal that helps authors manage contracts, invoices, and payment statements in one place.
The project replaced a largely paper-based administrative process with a more accessible digital experience built on Salesforce Experience Cloud.
The client had already defined the research, required content, and user flow. My role was to turn that UX direction into a complete visual system and working interface.

My Role

UI/UX Designer & Frontend Developer

I joined the project after the initial UX direction and wireframes had been established.

My responsibilities included:

  • Supporting the wireframe refinement
  • Building the UI system from the existing wireframes
  • Designing all screens and responsive states
  • Developing the frontend using HTML, CSS, and JavaScript
  • Collaborating with the client-side Salesforce implementation team
  • Adjusting designs to work within Salesforce's technical constraints

Another UX designer created the initial wireframes, which I took over and developed into the final UI. A frontend specialist also provided technical guidance throughout the implementation process. Salesforce implementation and backend integration were handled by the client.

The Problem

Authors needed to manage important documents such as contracts, invoices, and payment statements. The existing process relied heavily on paper and was not designed around a unified digital experience. The new portal also needed to support a wide range of users, including authors who may not use digital services frequently.

The challenge was:
How might we create a clear and approachable interface within Salesforce while maintaining a distinctive brand identity?

Project goals

  • Make important documents easy to find
  • Reduce cognitive load for users with varying digital literacy
  • Create consistent patterns across different document types
  • Provide a smooth responsive experience across desktop and mobile
  • Maintain Salesforce usability while expressing the publisher's brand
  • Create a UI system that could be implemented reliably within Salesforce process.

The opportunity

We could also use familiar enterprise UI patterns as a foundation rather than introducing completely new interactions.

Target Users

The primary users are authors who need to access documents related to their work with the publisher. The user base includes people with different levels of digital experience, including senior authors who may not regularly use online administrative services.

Authors managing administrative documents

Their main needs are:

  • Quickly finding the right document
  • Understanding information without technical knowledge
  • Checking payment and contract details
  • Accessing the portal comfortably on different devices

The interface therefore prioritizes clarity, familiarity, and low cognitive load.

User Flow

The overall user flow and information architecture had already been defined by the client before I joined the project.

Design System

Building a UI System from Existing Wireframes

The initial wireframes defined the content and overall structure. I took over the design process at this stage and developed the visual system across the entire portal.

The main focus was creating consistency across:

  • Typography
  • Color
  • Spacing
  • Buttons
  • Cards
  • Tables
  • Form elements
  • Navigation
  • Status indicators
  • Responsive behavior

The goal was to make each screen understandable without requiring users to learn how the system works first.

Typography & Information Hierarchy

Readability was a major consideration because users needed to scan administrative information quickly.

I used:

  • Clear type hierarchy
  • Generous spacing
  • Strong grouping
  • Consistent alignment
  • Distinct visual states

The goal was to make each screen understandable without requiring users to learn how the system works first.

Responsive Design

The portal needed to work across desktop and mobile devices. On mobile, the navigation was redesigned to preserve space while keeping destinations recognizable. Icons were paired with text labels to maintain discoverability, while scroll-based behavior helped keep navigation accessible without taking up unnecessary screen space.

Hi-Fi Screens

Dashboard

The dashboard provides a simple starting point for accessing the portal's main functions. Information is grouped by task rather than system structure, allowing users to quickly identify where they need to go. The visual hierarchy also establishes the publisher's brand from the first screen.

Document Lists

Contracts, invoices, and payment statements use consistent list patterns. This reduces the cognitive load of switching between different document types. Users can quickly scan key information and select the document they need.

Onboarding Screens

Users enter their personal and contact information in the first step. The progress indicator clearly shows where they are and what remains. For the address section, selecting a country other than Japan automatically disables the Japan-specific address fields, keeping the form relevant and avoiding unnecessary input.

Mobile Experience

The mobile layouts were designed around the same information hierarchy as desktop while adapting the navigation and content density to smaller screens. The goal was not simply to shrink the desktop layout, but to preserve the most important actions and information at smaller sizes.

Frontend Implementation

I translated the approved UI designs into responsive frontend code using:
HTML · CSS · JavaScript

I worked within the constraints of the Salesforce environment while keeping the visual system consistent with the approved designs. Results

The project delivered a unified digital portal for managing contracts, invoices, and payment statements.

The final design:

  • Replaced fragmented paper-based document access with a centralized digital experience
  • Created consistent UI patterns across the portal
  • Improved readability for users with different levels of digital literacy
  • Extended the publisher's brand into the Salesforce environment
  • Provided responsive layouts for desktop and mobile
  • Translated the approved UX structure into a production-oriented UI system

The project demonstrated how thoughtful UI design can add clarity and brand value even within the constraints of an enterprise platform.

Start with clarity, build consistency, and use visual design to add value without getting in the user's way.
